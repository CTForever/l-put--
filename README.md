# Täringumäng

Täringumäng on loodud minu lõputööna. Mängija võistleb arvuti vastu ning mängu tulemused salvestatakse faili.

## Failide kirjeldused

- `main.py` – käivitab mängu.
- `game.py` – sisaldab mängu loogikat.
- `dice_results.csv` – fail, kus näeb varasemaid mänge ja nende tulemusi.

## Kuidas mängu käivitada?

1. Ava kaust „lõputöö“.
2. Vajuta kaustal parema hiireklahviga.
3. Vali „Ava terminalis“.
4. Sisesta terminali käsk:

   `python main.py`

## Kuidas mängida?

1. Mängu alustamiseks sisesta oma nimi.
2. Seejärel sisesta `j`.
3. Vajuta ENTER, et alustada uut vooru.
