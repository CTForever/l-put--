-- Täringumäng --
Täringumäng on loodud minu lõputööna. Mängija võistleb arvuti vastu ning mängu tulemused salvestatakse faili.

-- Mida mis fail teeb? --
main.py – käivitab mängu.
game.py – sisaldab mängu loogikat.
dice_results.csv – fail, kus näeb varasemaid mänge ja tulemusi.

-- Kuidas käivitada? --
Vajuta 'lõputöö' kaustale parema hiire nupuga.
Vajuta 'ava terminalis'
Sisesta käsk:
python main.py

Mängu alustamiseks sisesta oma nimi ja vali j.
Kasuta nuppu ENTER, et mängus uus voor algaks.
